
# Mi_App_FlaskMongo1

## Descripción

Mi_App_FlaskMongo1 es una aplicación web desarrollada con Flask y MongoDB.
El proyecto permite gestionar información mediante una interfaz web,
utilizando formularios HTML y una base de datos NoSQL.

La aplicación utiliza plantillas HTML para mostrar y editar información,
así como archivos CSS e imágenes para mejorar su presentación.

## Tecnologías utilizadas

- Python
- Flask
- MongoDB
- PyMongo
- HTML5
- CSS3

## Instalación y ejecución

1. Clonar el repositorio:

   git clone URL_DEL_REPOSITORIO

2. Entrar a la carpeta del proyecto:

   cd Mi_App_FlaskMongo1

3. Crear un entorno virtual:

   python -m venv Mi-Entorno

4. Activar el entorno virtual en Windows:

   Mi-Entorno\Scripts\activate

5. Instalar las dependencias:

   pip install -r requirements.txt

6. Ejecutar la aplicación:

   python app.py

7. Abrir el navegador y entrar a:

   http://127.0.0.1:5000
